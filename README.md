# João Adriano — Portfolio

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, and an animated 3D hero (Three.js / React Three Fiber).

## Features

- Animated 3D particle globe hero built with `@react-three/fiber` + `@react-three/drei`
- Smooth scroll-reveal animations with `framer-motion`
- Sections: Home, About, Skills (filterable), Projects, Services, Testimonials, Contact
- Fully responsive, dark theme, glassmorphism UI

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) / [drei](https://github.com/pmndrs/drei)
- [Framer Motion](https://www.framer.com/motion/)

## Build

```bash
npm run build
npm start
```
